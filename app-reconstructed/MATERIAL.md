# Material 样板：P0 / P1

## P0：兼容性基线

- 从 `c0ffa10`（0.0.9 / versionCode 11）开始，保留热度、排行榜、分页与刷新修复。
- 新增固定依赖 Material 3 `1.4.0` 和 Material Icons Core `1.7.8`。
- 不引入 Compose BOM，不升级既有 AGP、Kotlin、Compose 或 Miuix。
  实际解析为 AndroidX Material 3 1.4.0；Compose 仍沿用既有 1.11.2 Android 依赖线。
  详细 runtime classpath / dependencyInsight 保存在本机验证记录中。
- Material 颜色、排版、形状集中在 `ui/designsystem/PocketMaterialTheme.kt`；
  不读取或改写旧主题偏好，不嵌套到旧 Miuix 页面内。
- 原 394 项测试及新增 Material 组件试编测试通过，Android debug APK 构建成功。
  这只证明依赖与基础组件可运行，不代表真机性能或全部页面迁移完成。

## P1：可运行样板

版本 `0.0.10-material-preview` / versionCode 12。入口：**设置 → Material 预览**。
独立 Activity，原应用外壳、主题和业务页面仍保留；P2–P5 尚未实施，样板布局与密度等待用户确认。

### 如何使用

1. 默认离线，使用本地矢量风景图和实际 `DanbooruViewModel`，不发网络请求、不改真实配置。
2. 右上角菜单可切换正常、空结果、首次失败、追加失败和长标签。
   首次／追加失败为一次性演示，重试可恢复；演示数据不冒充真实榜单。
3. 菜单可选浅色、深色、跟随系统或动态取色，仅影响样板，不改旧主题偏好。
4. 五个主入口只演示导航与内容层级，P1 仅「画廊」实现内容闭环。
   其他四页明确标注导航演示，原业务仍从原界面使用。
5. 选择「连接现有 Danbooru」并确认，才使用现有独立 Runtime／Repository／账号／代理。
   热度、评分、收藏和日／周／月榜沿用 0.0.9 服务端查询，不在手机上重排当前页冒充全站排序。
6. 在线模式设置页主动保存会更新真实 Danbooru 配置；离线保存只作用于本次演示。
   两者在界面和成功反馈中明确区分；测试当前输入不执行保存。

### 页面与交互

- 标准 Material 底部导航、TopAppBar、筛选面板、Snackbar、Dialog 和独立长表单页面。
- 纯图片瀑布流与清晰 sample 缓存，列表无帖子编号；短列表、空结果和失败均保留 PullToRefreshBox 入口。
- 详情隐藏主导航，支持全屏图与双指缩放。元信息与 Tag 面板分层；
  Tag 支持单项复制、跨组多选、全选组、复制全部／提示词和折叠格式选项。
- 设置按账号／代理／偏好分组，保存／取消固定在底部；就地校验、失败保留输入。
  离开脏表单可保存、放弃或继续编辑。Activity-retained ViewModel 保留旋转后的草稿，
  凭据不写入 SavedState，进程结束后不承诺恢复未保存草稿。
- 系统栏、输入法和内容使用统一 Insets；控件保留 Material 最小触摸区域。
  重复点击当前导航不刷新／跳顶，切回画廊保留查询与滚动。
- 在线保存／分享调用原有 `DanbooruRuntime.original`，复用原始字节缓存，不压缩缩略图冒充原图。
- 另一界面在暂停期间保存配置后，恢复时清掉旧账号窗口并重查；
  没有改动网络、认证、缓存键、Agent、通知或其他服务配置。
