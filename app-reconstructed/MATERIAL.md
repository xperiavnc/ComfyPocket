# 底栏风格与页面切换

当前版本：**0.0.19-navigation-styles / versionCode 21**（2026-10-18）。
P3–P5 已按用户要求通过新提交回退，当前业务页面保持 P2 完成时的界面。

## 当前版本

- 在 **设置 → 主题与外观 → 底栏风格** 中选择「标准底栏」或「经典悬浮」。
  即时生效并持久保存，重启后继续使用所选样式；已有安装默认保持标准底栏。
- 标准底栏保留现有 Material 导航和选中指示器的平滑移动、图标对齐；
  经典悬浮复用老版胶囊、五个图标、点击/拖动及弹性指示器，不自动启用旧液态玻璃偏好。
- 两种样式共用路由、返回栈、页面状态和老版页面动画：
  进入从页面宽度的 1/5 滑入、旧页向左移动 1/8，滑动和淡入 280ms，淡出 220ms；
  返回反向，RTL 镜像。没有因底栏样式而采用另一套页面动画。
- Danbooru 点按图片进入标签详情、返回图片列表也使用这套动画。
  退场详情保留数据快照；标签选择、复制、详情加载和列表刷新不重新播放页面动画。
  列表滚动位置、单层返回和取消预测返回语义保留。
- 悬浮底栏仅在可见时为内容提供避让，二级页不留空白；
  键盘显示时两种底栏均隐藏，系统安全区和输入法避让不重复计算。
- **Material 预览已删除**：移除设置入口、独立 Activity、演示页面、演示资源和专属测试。
  正式导航所需的 Material 依赖与主题仍保留。
- 未自动安装、卸载、清数据或提交真实生成任务。
  自动交互/布局测试不代表手机上的帧时间、系统输入法和主观手感已经实测。

以下保留 P0–P2 的实施历史；其中预览入口及早期动画参数不代表当前版本。

## P2 历史：正式应用外壳

- 主页、控制、Agent、应用、画廊使用固定 Material NavigationBar；
  二级页面隐藏底栏，主入口仅对内容做 12dp / 180ms 转场。
  二级进入 32dp / 220ms、返回 180ms，方向与样板一致；快速切换可中断。
- 沿用原来的持久路由名与 Navigation Compose 多返回栈，不重写业务状态。
  重复点当前入口不导航、不刷新；切回保留可保存的草稿、筛选与滚动位置。
  Agent 历史阅读位置不再因重新进入 Tab 跳到底部，画廊服务器 / 本地各有保存状态。
- 返回优先由当前页弹层、多选或详情消费；非主页根返回主页并保存离开页，
  主页交系统退出，未增加新的退出确认。预测返回取消不提交跳转。
  退场页面保留渲染，但停止接收返回、触摸和无障碍操作。
  保留集市单次返回 gate 和后台资源释放逻辑，没有重做集市网络层。
- 外壳统一处理横向安全区、底部系统区与 IME，旧页面继续负责顶部状态栏。
  内容实际布局在底栏之上，不再使用玻璃底栏的虚拟避让高度。
  键盘显示时隐藏主导航；Agent 使用消费 Insets 的修饰符，避免键盘高度计算两遍。
- 前台 ViewModel 的短反馈由一个 Material Snackbar 展示，跨 Tab 保留；
  无前台订阅时仍回退 Toast，不同时弹两种提示。生成通知策略不变。
- 原深浅色、跟随系统、八种色板与 UI 缩放继续读取原配置；
  通过显式适配映射外壳颜色角色，不清空偏好、不强制动态取色。
  Miuix 主题、Scaffold 与 OverlayDialog 的返回宿主仅包围旧页面，不包围 Material 底栏和反馈。
  不再展示无效的「液态玻璃导航」开关；旧偏好保留以支持回退，旧库与文件待 P5 清理。

### 如何使用

1. 默认离线，使用本地矢量风景图和实际 `DanbooruViewModel`，不发网络请求、不改真实配置。
2. 右上角菜单可切换正常、空结果、首次失败、追加失败和长标签。
   首次／追加失败为一次性演示，重试可恢复；演示数据不冒充真实榜单。
3. 菜单可选浅色、深色、跟随系统或动态取色，仅影响样板，不改旧主题偏好。
4. 五个主入口只演示导航与内容层级，P1 仅「画廊」实现内容闭环。
   其他四页明确标注导航演示，原业务仍从原界面使用。
5. 选择「连接现有 Danbooru」并确认，才使用现有独立 Runtime／Repository／账号／代理。
   热度、评分、收藏和日／周／月榜沿用 0.0.9 服务端查询，不在手机上重排当前页冒充全站排序。
6. 在线模式设置页主动保存会更新真实 Danbooru 配置；离线保存只作用于本次演示。
   两者在界面和成功反馈中明确区分；测试当前输入不执行保存。

### 页面与交互

- 标准 Material 底部导航、TopAppBar、筛选面板、Snackbar、Dialog 和独立长表单页面。
- 纯图片瀑布流与清晰 sample 缓存，列表无帖子编号；短列表、空结果和失败均保留 PullToRefreshBox 入口。
- 详情隐藏主导航，支持全屏图与双指缩放。元信息与 Tag 面板分层；
  Tag 支持单项复制、跨组多选、全选组、复制全部／提示词和折叠格式选项。

## P1 补充：切换、进入与返回动效

这一批历史改动仅作用于 Material 预览；后续 P2 已将相同距离与时序接入正式外壳。
沿用现有 Compose animation，没有引入额外动画库或改动工具链。

| 场景 | 动效 |
| --- | --- |
| 五入口切换 | 底栏固定，内容按 Tab 顺序轻移 12dp 并淡入淡出，180ms；重复点当前入口不触发跳转 |
| 进入详情／设置 | 32dp 横向进入与淡入，220ms；上一层仅轻移 8dp，避免整屏长距离飞入 |
| 返回上一层 | 与进入方向相反，180ms；工具栏与系统返回使用同一页面状态变化 |
| 全屏图打开／关闭 | 180ms 淡入、140ms 淡出，退场结束才移除图片，双指缩放行为保留 |
| Tag／外观／确认弹层 | 沿用 Material 组件自带过渡，不额外叠加整页动画 |

- 动画可中断，快速切换收敛到最后选中的页面，不排队播放。
- 页面先淡出再淡入，避免两页图片与文字长时间重叠；底层使用主题 surface，不闪黑屏。
- 以路由而非加载结果作为动画 key，刷新、追加、详情请求完成不会重新播放进入动画。
- 返回时保留退场页的不可变数据快照，不因 ViewModel 已清空 detail 而先闪成空白。
  退场内容屏蔽触摸与无障碍操作，退场设置页停用返回处理，避免抢走下一次返回。
- 页面切换清理旧焦点；画廊查询、滚动位置、设置草稿和原有单次／取消预测返回语义保留。
  返回动画在返回动作确认后播放，不声称实现了随预测返回手势进度逐帧拖动。
- RTL 自动反向；遵循 Compose 的系统动画倍率，倍率为 0 时不等待标称时长。
  不使用模糊、列表尺寸动画或对大图重新采样来制造转场。
- 真机帧时间、掉帧和主观手感未测量，自动时钟与布局截图不作为“真机绝不卡顿”的证据。
  本批交付与源码回滚放在本机 `artifacts/material-motion/`，隔离回滚目标为 0.0.10 / 12。
