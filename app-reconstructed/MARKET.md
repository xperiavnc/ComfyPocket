# 集市第一阶段

## 手机侧

- 默认手机直连 Civitai，无需电脑在线即可搜索、筛选和查看详情。
- 独立 `MarketViewModel`、网络客户端和搜索状态控制器，不继续扩充主 ViewModel。
- 集市右上角设置中可切换手机直连 / 电脑桥接，配置手机 HTTP 代理、
  可选代理认证和 Civitai Key。
- Key 与代理密码由 Android Keystore 加密，排除在普通配置导出之外。
  正常校验 Civitai TLS，不继承本地 ComfyUI 连接的证书例外。
- 列表、模型和版本元数据 5 分钟缓存；断网可显示过期缓存，
  401 / 403 / 404 不用旧数据掩盖访问拒绝。
- JSON 缓存按来源、账号和内容级别分区，最多 60 条 / 16 MiB；
  图片缓存 96 MiB，代理热切换会作用于后续图片请求。
- 搜索取消旧请求并检查代次；分页按模型 ID 去重，加载更多不会混用输入框的新草稿。
- 模型简介、版本说明、触发词和预览图可查看；API 有图片元数据时显示对应的
  正向/反向提示词和参数，可复制。补充的社区示例与作者预览明确分开，
  缺少提示词时直接说明，不生成或猜测。
- HTML 简介以惰性文本展示，不执行脚本。长内容整体滚动，下载栏保持可见。

## 联动电脑

手机浏览 Key 不等于电脑下载 Key。电脑下载需要配套 Bridge 2.0：

**ComfyUI 设置 → Mobile Bridge → Civitai → Civitai Key（电脑端下载）**

安装、服务端 Key 存储、代理、原生队列和回退见
`ComfyUI-Mobile-Bridge/README.md`。

手机的版本 / 文件 / 目录选择继续保留；电脑用官方文件 ID 重新验证下载。
手机与电脑可使用不同账号，手机匿名浏览的 `canDownload` 不阻止电脑再次验证权限。
手机未列出文件时，按钮明确说明由电脑按所选版本选择主文件。
新增下载队列弹窗，只在弹窗可见、应用前台且已连接电脑时轮询，
支持暂停 / 继续 / 取消。旧插件缺少 `native-*` 接口时明确提示更新。

Key 只提供账号原有的访问权限，站点内容级别、购买/抢先体验和地区限制仍然生效。
某个版本出现在列表里不保证当前账号具备下载权限。

## 未改动与验证边界

- 不改底部导航、切换动画或其他页面的工作流编辑状态。
- Bridge 是单独安装的 Python 插件，不打包进 APK；升级需替换整个插件目录并重启。
- Android 的常规 ComfyUI 连接仍沿用原有证书策略，本次只给 Civitai 直连使用独立
  正常 TLS 客户端，不宣称已修复应用所有网络策略。
- 自动化测试覆盖 JSON、代理、TLS、缓存、搜索竞态、原生下载路由、Key 设置和队列。
  本地浏览器烟测使用模拟 Key；不等价于真机、真实 Key、真实代理或付费模型下载验收。
